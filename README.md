# Scope CLI contribution demonstrations

Paced terminal playback of actual commands using synthetic local release and downloader fixtures. No live GitHub downloads, credentials, or production data. These are rendered command-output recordings, not screen captures.

- `release-before` / `release-after`: skip draft and prerelease versions when updating.
- `update-before` / `update-after`: preserve the working installation when a download reports the wrong version.

MP4 recordings have matching plain-text transcripts and asciinema casts. The casts use paced event timing for readability. Recordings were produced on 2026-11-04 against baseline 05d94350 and fixes 2101fd60 / 2b95676f.
